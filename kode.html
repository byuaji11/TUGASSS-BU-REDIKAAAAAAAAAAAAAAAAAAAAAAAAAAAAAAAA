Kode Program ESP32

Sketch ini membuat access point Wi-Fi pada ESP32 dan menyediakan halaman kontrol mobil melalui browser.

  1. Buka file sketch pada Arduino IDE atau PlatformIO.
  2. Sesuaikan nama Wi-Fi, kata sandi, serta pin motor dengan rangkaian Anda.
  3. Unggah program ke ESP32, lalu hubungkan ponsel ke jaringan yang dibuat perangkat.
  4. Buka http://192.168.4.1 untuk mengakses kontrol.
Peringatan: Kode ini ditujukan untuk ESP32. Jangan unggah ke Arduino Uno. Sesuaikan kata sandi Wi-Fi dan lakukan pengujian dengan roda terangkat terlebih dahulu.
