📶 Kendali langsung melalui Wi-Fi

ESP32 membuat hotspot sendiri. Sambungkan ponsel ke jaringan RC_Car_ESP32, buka 192.168.4.1, lalu kendalikan mobil dari halaman kontrol.

🤖 Tentang Proyek

Proyek ini menggunakan ESP32 sebagai pengendali mobil RC. ESP32 membuat access point Wi-Fi dan menyajikan halaman kendali lokal; perintah dari browser mengatur arah motor melalui driver L298N. Kendali tetap tersedia tanpa koneksi internet maupun modul Bluetooth tambahan.

⚡ Fitur Utama

Kendali sederhana melalui jaringan lokal ESP32.

📱

Kendali via Browser

Tombol arah dapat digunakan dari browser ponsel atau komputer.

📶

Hotspot ESP32

ESP32 membuat jaringan Wi-Fi sendiri tanpa router atau internet.

🛑

Berhenti Otomatis

Motor berhenti saat tombol dilepas atau perintah kendali terputus.

🔄 Cara Kerja

01

Sambungkan Wi-Fi

Pilih jaringan RC_Car_ESP32 dan masukkan kata sandi yang disetel di sketch.

02

Buka kontrol

Buka alamat lokal 192.168.4.1 pada browser.

03

Kirim perintah

Tekan dan tahan tombol maju, mundur, kiri, atau kanan.

04

Motor bergerak

ESP32 mengatur input driver L298N sesuai perintah.
